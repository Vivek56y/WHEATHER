# 🌦 Weather App

This is a responsive and user-friendly **Weather App** that allows users to get real-time weather updates for any city using the **OpenWeatherMap API**.

## 🔧 Features

- 🔍 Search weather by city name
- 🌡 Displays temperature, humidity, weather condition, and more
- 📍 Default weather info for a selected country
- ⚠ Error handling for invalid inputs
- 🎨 Clean, responsive UI (HTML, CSS, JavaScript)
